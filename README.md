# Website demo remake

A hand-written static remake of the structure of the wellness-coach demo at
`myhra-demo.squarespace.com`: the same set of pages, the same navigation and the
same section-by-section layout, with no site builder behind it.

The source is Squarespace's own template, so its wording, photographs and licensed
fonts are **not** copied here. The copy is new placeholder text, the images are tonal
placeholders, and the fonts are open-licensed (Marcellus and EB Garamond from Google Fonts).

## View it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8765
```

Then visit `http://localhost:8765`.

## Change it

The pages are generated by `build.py` (Python 3, no dependencies).

1. Edit `SITE_NAME`, `COACH_NAME`, the prices or any wording in `build.py`.
2. Run `python3 build.py` to regenerate the `.html` files.
3. Run `python3 check.py` to re-run the checks and rewrite `REPORT.md`.

Colours and fonts are set once at the top of `assets/styles.css`.

## What's here

| Path | What it is |
| --- | --- |
| `index.html`, `about.html`, `services.html`, `coaching.html`, `seasonal-recipes.html`, `meal-plans.html`, `work-with-me.html`, `contact.html` | The main pages |
| `recipes/` | Five recipe posts |
| `assets/` | Stylesheet, a small script (mobile menu, demo forms) and favicon |
| `build.py` | Generates every page from one shared header, footer and nav |
| `check.py` | Checks the pages and writes `REPORT.md` |
| `checks/browser.json` | Recorded results of the checks that need a real browser |
| `REPORT.md` | The current check report |
